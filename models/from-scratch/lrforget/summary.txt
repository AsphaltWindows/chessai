LR GRADUAL FORGETTING (--lr-memory), 2026-11-10

Task: test the user's hypothesis that gradual forgetting helps LR, and helps more on a diverse (mixed-architecture)
local stream. Build an option that makes LR's AdaGrad step size stop shrinking, at a memory matched to probit's default
tau, and draft (not create) two experiments: a flat-only stream and a mixed stream.

BINARY
- models/from-scratch/bin/chessai-hybrid6f (md5 2ea8c5100c82c34b83d73409f0025284), built from src-h6f/, a copy of
  fastbin/hybrid6-src. rs/ and the other binaries are untouched. cargo -j 2, nice.
- train --lr-memory M (default 0: off). For --model lr, and for bdt/bdd with --leaf lr (not --leaf-residual).
  Refused for self-play, for probit or NB leaves, and for M below 2.

DESIGN
- Plain AdaGrad: squares += g^2; w -= rate * g / sqrt(squares). The step shrinks like 1/sqrt(uses) forever.
- With memory M: each time a weight is used, squares = squares * keep + g^2, with keep = 1 - 1/M, then the same
  step. squares levels off near M * mean(g^2), so the step stops shrinking after about M uses: an RMSProp-like
  window of M uses.
- Applies only to flat LR models and LR leaves. Routers and error routers never forget, because LR routers keep their
  own LR objects. Shadows and children made at a split inherit the leaf's memory.
- Off is the old code: step() calls the decayed step only when memory != 0, and the original code follows unchanged.
- The decayed step has an AVX2 path, the same as the plain step's, with separate multiply, multiply and add (no FMA).
  It is bit-identical to scalar, and a unit test checks it.
- The memory is recorded only when it is on, so an off run's files are the old bytes:
  - a flat model file gets a trailing line "memory 6e6". Old readers ignore it, so hybrid7 plays the file.
  - an LR state sets a flag bit on class_num and adds the f64.
  - a tree's options string, which its state checks on resume, gains ", lr_memory: M" only when M != 0.
  - Resuming with a different --lr-memory than the --start model or state is refused.

CHECKS (check_lrforget.sh, log check_lrforget.log, fail=0)
- Unit tests: 158 + 1 passed. New tests:
  - the step levels off. With M = 1000, the sum of squares changes under 5% from pass 2 to 9, while plain's grows
    more than 3x. It sits within 20% of M * mean g^2, and the step ends more than 4x plain's.
  - the AVX2 decayed step equals a scalar reference bit for bit.
  - the memory survives files and states, and plain files and states are unchanged.
  - in a tree, the memory goes to leaves only, and a state refuses a different memory.
- Off: byte-identical to chessai-hybrid6 in models, states and train output, over version 0, two rounds in one go,
  and the same rounds in pieces. Checked on F-L (--use-probs) and on T-L-Nc at limit 4, threshold 20k (it splits).
- On, at M = 1000 and 2e7:
  - one go equals the same rounds in pieces with --start, for flat models (via the trailer) and for tree states;
  - 4 threads equal 1 thread;
  - the memory changes the models.
- Refusals: ten cases, all refused with clear errors.
- Play: hybrid7 arenas give byte-identical games and logs with the trailer file and the same file stripped, in plain
  and cal: mode. hybrid7 plays the forgetting tree.
- The exact league line (version 0 from no games, then --start, at --lr-memory 6000000) works. "6000000" and "6e6"
  give the same model. --start without the flag is refused.

M CHOSEN: 6e6 (6,000,000 uses)
- Probit's memory at tau 1e-5:
  - each use adds tau^2 to a weight's variance s2 and shrinks it by s2^2 * w / S^2. At equilibrium these balance.
  - so the per-use gain (the fraction of the error absorbed) is s2*/S^2 * w = tau^2 / s2*, and the memory is
    s2*/tau^2 uses.
  - measured on cluster-error's F-P version 585 (bias): s2* = 1.446e-5, about 1.45 tau, so the memory is about
    1.45e5 uses. The user's round numbers (~200k positions, floor ~2 tau) are the same estimate.
- Decayed LR at equilibrium:
  - squares ~ M * E[g^2], so the per-use gain is rate * h / sqrt(M * E[g^2]), where h is the curvature E[p(1-p)];
  - for a calibrated model E[g^2] = h = q, so the gain is rate * sqrt(q / M).
- Equal gains give M = q * (rate * memory_probit)^2.
  - With rate 0.05 and q = 0.111 (F-L version 585's bias: G/n over n = 463.5M uses; W 0.133, L 0.134, draw
    0.065), M = 5.8e6, so 6e6. The per-class values would be 7.0e6, 7.0e6 and 3.4e6.
  - With the user's 2e5, M would be 1.1e7. The step scales as 1/sqrt(M), so that factor of 2 is only 1.4x in step.
- At M = 6e6, the bias's gain levels off at 6.8e-6, against F-P's 6.9e-6.
  - Plain F-L passes that gain after about 6e6 bias uses (~21 cycles at the drafts' ~280k positions a cycle).
  - After that, plain F-L's step keeps shrinking: about 5x smaller than the forgetting line's by cycle 600.

SIDE FINDING (the step-size trace offered for decision 1)
- In cluster-error at version 585, F-L's per-use bias gain is 8.5e-7, against F-P's 6.9e-6. LR moves 8-12x more
  slowly than probit per use, across classes.
- This is the candidate mechanism for F-P catching F-L there: LR's steps die out, while probit's tau keeps its steps
  alive.
