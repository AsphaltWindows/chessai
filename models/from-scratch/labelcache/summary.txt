chessai-treelab2: chessai-treelab plus the shared label cache (distill fork, 2026-11-13; fastbin review-1113c's
candidate 1, approved with the distillation run: the coordinator's directive 11-13 ~12:55 on the user's go)

WHAT
The distillation runs (distill-p2-s1/s2) train six trees/DAGs a cycle with --label-depth 2 --label-result 0.5
--label-model F-P on the same set (trainsets/local) and the same labeller (the F-P line's current version): six
identical computations of fit_calibration + search_labels. treelab2 computes them once: the first line to need them
computes and keeps them in <games>/.labelcache/labels-<128-bit key>.bin, the others read them.
- src: labelcache/src = tree-labels/src (treelab e7d31b0e...) + src/src/labelcache.rs (new) + lib.rs (pub mod) +
  main.rs (Command::Train begins the cache before the labeller loads, only with --label-model and --label-depth;
  train_rounds_labelled takes it and computes through Keyed::labels; own-search labels are never cached).
- key: "chessai labels key 1", the binary's bytes (/proc/self/exe digest), the CHESSAI_* environment less
  CHESSAI_LABELCACHE (sorted; any *_STATS/*_CHECK turns the cache off), the labeller's kind, --use-probs and file bytes
  (digested before it loads and again when keying: changed meanwhile = no cache), the depth, the result weight's f64
  bits, and the round's records in read order (count; each game's result, movetext, move count, positions). Parts as
  128-bit digests (two XXH64s with the length, hybrid16's calcache code); the entry holds the whole key, compared in
  full, then the calibration and every label as f64 bits, then a checksum. A hit must also match the round's shape.
- only labeller kinds that load exactly one file (cnbp, lr, probit, bdt, bdd); anything unexpected = compute as before.
- locking: a miss takes flock (std File::lock) on labels-<key>.lock, looks again, computes, writes (unique temp file,
  rename), unlocks: of lines started together one computes, the rest wait and read. Kernel drops the lock on death.
- CHESSAI_LABELCACHE=off: the cache off; =log: one stderr line a round (stdout unchanged).
- disk: one entry a cycle a run (~24 bytes a position: ~5-8 MB), removed with trainsets/ at the cycle's end.
