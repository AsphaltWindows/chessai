Command: python3 leagues/leagues.py extend LEAGUE --cycles N [--dry-run]
  An experiment that ended at its cap C (not on its plateau rule) goes on to cap N as if N had been its cap from the
  start. Cycle C (it rated and decided but trained nothing) runs again as an ordinary cycle from the state at the end
  of cycle C-1 (a crowning in it undone); its games are cut and replayed (rounds seeded by number). The originals go
  first to <league>/extend/cap-C/ (with the old finals' models and training states: a warm-start source); the cycle
  that runs again checks itself against them (field, games, decisions, ratings, plateau) and fails on a difference.
  config.json: cycles N plus a cap_history entry; the cycle report, status, the dashboard and the library show it.
  After extend, start the run's repeat.sh again (it exits when the run is done).
  Refused, changing nothing: not an experiment, a driver holds it, not done, ended on its plateau rule, N <= C, N not
  a rated cycle under rate_every, options the test doesn't cover (self-play/global lines, replay, train_filter,
  frozen_references, self_games_topup, reference_window), records that don't line up, extend/cap-C/ already there.
