METHOD (why the values can't change)
- root_values gives every root move a full window (-inf, inf). Alpha-beta (fail-soft here) returns the exact minimax
  value of a node searched with a window containing that value, whatever the move order. Values are the leaves' values
  negated, never summed, so there is no rounding to reorder. A node's value depends only on its path (repetitions
  via the hash stack, which is restored after each child, and mate distance via the ply), not on its siblings'
  order. There is no transposition table or other memory across siblings. So each root value is bit-identical, and
  so are the softmax, the argmax ties and every game. Only the nodes visited change.
- The outcome search takes its principal variation's leaf. With tied values a different order could pick another
  leaf, so it keeps hybrid9's order.
