METHOD
- Item 1. The estimate only chooses which replies are valued in float (compound::best: replies whose lower bound is
  at most the smallest upper bound); negamax's loop then runs over those in move order, so values, ties and moves are
  unchanged as long as every estimate is within its bound.
  - The table value's distance from the float ln Phi at the same z, and from the true ln Phi there, is bounded by
    fastprobit::ln_phi's err (hybrid8's proof: chord + h^2/16 within h^2/16 since -1 < (ln Phi)'' < 0; the table's
    and the float ln Phi's approximations; interpolation and x rounding).
  - The exact path's float ln Phi at its own z is allowed 1e-13 + 16u |ln Phi| each, as before, with |ln Phi| there
    under |l| + 1. The move from the estimate's z to the exact z is covered by hybrid5's derivative and z-rounding
    terms, unchanged. So approx = ew + eb + 2e-13 + 16u (|lw| + |lb| + 2), then hybrid5's x4 and 1e-10.
  - |z| > 29.5: hybrid8's rational ln Phi and its allowance.
  - The looser bound (about 1e-5 instead of 1e-12) values no extra replies in float: CHESSAI_FX_STATS on two T-P@2
    entries, 10 games: 937,792 depth-2 replies, 40,597 valued in float (0 beyond one per position), the same counts on
    hybrid8 and hybrid9.
- Item 2. A model never changes during play, and every game builds each side's fixed-point state afresh (compound_of,
  fixed_of), as self-play already does with one model for both sides; the calibrated model's compound tables are a
  OnceLock built from the model alone. So one load serves A and B.
