LR ANCHOR (--split-anchor-l2), 2026-11-11

Task (theory-2 6.23 item 4): copy-on-split LR leaves that keep a frozen copy of the parent's weights at the split and
are pulled towards it by an L2 penalty, strength matched to the probit trees' split noise 0.03 (the probit mechanism
of 6.14 done for LR). Build it off by default and byte-identical when off, check it, sweep the strength offline on
held-out games, draft (not create) the league test.

BINARY
- models/from-scratch/bin/chessai-hybrid6an (md5 26195379e1cd11f1e046bcbf69755561), a new file; built from
  lranchor/src-h6a/, an rsync copy of fastbin/hybrid6-src (the lines' training binary chessai-hybrid6). rs/ and every
  other binary untouched. cargo build --release -j 2 under nice 19, CARGO_TARGET_DIR=lranchor/target.
- train (and self-play) --split-anchor-l2 L, default 0 = off. Only for --model bdt with --leaf lr, without
  --leaf-residual or --leaf-share. Refused with one clear error (checked): flat lr, probit leaves, residual leaves,
  --leaf-share, a negative L, and --model bdd (DAGs: not enabled).

DESIGN
- A split's new leaves, and leaves reset to their delegator's shadow (--reset-leaves), get an anchor: a frozen copy
  of the weights they start from (the parent's at the split), a per-weight stamp `last` and a counter t of the
  examples the leaf has trained on since. Shadows, trial copies and merged leaves get none; a leaf that splits drops
  its anchor (it is a delegator now). Model files are unchanged (plain LR leaves): hybrid13 and hybrid4gfx load and
  score them identically (checked).
- After each AdaGrad step of an anchored leaf, every weight the example used (the bias and one value per feature, each
  class) gets the proximal step of the penalty L/2 (w - a)^2 for each of the k examples since its last pull:
      w = a + (w - a) / (1 + eta * L * k),   eta = rate / sqrt(squares) (the weight's AdaGrad step size)
  k counts the examples the weight missed, so the penalty is L per weight per example of the leaf, as a dense penalty
  (lazy, so the cost is per used weight). Weights with no AdaGrad history are not pulled. The penalty does not enter
  the AdaGrad sums. (The lazy form applies the k missed pulls after the step instead of before it; same equilibrium
  to first order, a little tighter for weights with eta*L*k ~ 1.)
- Equilibrium: a weight used by a fraction f of the leaf's examples settles at a + (w* - a) f v / (f v + L), with v
  ~ 0.2 the softmax curvature: weights used by fewer than L/v of the leaf's examples stay near the parent, common ones
  follow the leaf's data. (--residual-l2 instead shrinks every weight by the same factor, S1 of 6.1.)
- State files hold the anchors (t, weights, stamps) only when L != 0; the tree's option string gains
  ", split_anchor_l2: L" only when L != 0, so off runs write the old bytes and a state written with the anchor is
  refused without it.

STRENGTH (the derivation)
- Probit trees widen each child's weights by s^2, s = 0.03, at a split: the child's prior is ~N(parent, s^2) in probit
  units (beta = 1; the parent's own posterior variance is far below s^2 for any weight it has used much).
- Units: near even positions the ordered probit's win/loss log-odds move 2 phi(eps)/Phi(-eps) = 2.28 per unit of
  latent (eps = 0.5); an LR class weight moves them by itself, and the win and loss weights' difference has width
  sqrt(2) s_L. sqrt(2) s_L = 2.28 * 0.03 gives s_L = 0.048 per LR class weight.
- A prior of width s_L is a total penalty (w - a)^2 / (2 s_L^2); the anchor's is L/2 (w - a)^2 per example, N L/2 after
  N examples. Matching them at N_ref, a new child's examples in one gate window (split threshold / branch factor):
      L* = 1 / (s_L^2 N_ref)
  League (threshold 1M, branch 3): N_ref = 333k, L* = 1.3e-3. Testbed (threshold 300k): N_ref = 100k, L* = 0.0043.
  Recipe default (5M): 2.6e-4. (Without the unit conversion, s = 0.03 itself: 3.3e-3 and 0.011.)
- The anchor is weaker than the probit prior before N_ref and stronger after (a tether, not a prior that washes out).

  lost 0.003 with a root merge in all three seeds. Offline, then, the prediction is no gain over plain copies (a
