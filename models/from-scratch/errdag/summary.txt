2. The knob: --router-split-z Z (train, BDD only; a BDT refuses it)
- It gates the delegator (router) split decision in bdd.rs check_delegator_split. It is a port of bddtrig2-q9's
  "2b" rule. It fits as-is: the same window bookkeeping, only the test changes.
- After each window of split_threshold examples, close_window gives:
  - recent: the window's mean router error;
  - previous: the previous window's mean;
  - margin: Z x sqrt(se_recent^2 + se_previous^2).
- With Z, a delegator splits iff all three hold:
  - previous >= 0;
  - recent - previous > margin (its error rose by more than Z standard errors);
  - recent >= the mean router error of all routers over the window.
- Without the flag: the old stall rule (previous - recent < margin at --split-z). Z = 0 is exactly the stall rule
  at --split-z 0 (test: byte-identical models). Z = inf never splits a router; the DAG then makes only leaf splits.
- Leaf splits are unchanged: they still use --split-z.
- The split limit still counts leaf and router splits together.
- Training only: not saved in model files; written in state options only when set.
- Leaf-agnostic: the rule reads only router errors, so a probit-leaf BDD gets it for free.

4. What a probit-leaf BDD port (in errdag-src) would need. Not built.
- CLI: --model bdd accepts only LR/CNBP leaves today ("BDT only" for probit). It needs:
  - --leaf probit;
  - --split-noise for the BDD's leaf splits (the probit leaves' symmetry breaker);
  - probit_shared_eps.
- Path cells for probit nodes: one latent-mean weight posterior per (cell, value, class), prior N(0, noise^2) (the
  analyst's addendum). The cell's value shifts the node's latent means, the way the LR/CNBP cells shift log-odds.
  Each copy's update needs the probit moment-matching step with the cell weights included.
- Errors and context code for probit leaves: prediction_errors / home_errors and pathctx's per-node context
  application and update.
- Formats: the model and state formats (the pathcontext registry plus probit cell blocks) and the loader.
- Tests: the identity harness carries over unchanged. Without --path-context and at --router-split-z inf, a
  probit BDD must make the same splits and play the same games as a T-P-Ne BDT.
- Already leaf-agnostic: the router-split knob (it reads router errors only) and the identity harness.

- Reading:
  1. Between 0 and 10 the knob does nothing. The router-error rises that trigger splits are about 10-100 SE:
     z 30 drops some (seed 12, so some rises are 10-30 SE), and z 100 drops all.
     - They are drift: the routing target (the best of the shared children) changes as the copies diverge. They are
       not noise, so z does not act as a significance level.
     - Drift t grows with the window. With the live 1M threshold, expect about sqrt(10) = 3x the SE count, so the
       sweep's z 30 is roughly z 100 there.
  2. No z beats the tree.
     - Winner log-loss is within 1.5 SE of the tree everywhere.
     - Full log-loss is slightly worse with path context at low z (0.0030, 2.3 SE) and seed-dependent.
     - Router splits without context are equal.
     - The home target is no better.
  3. Limit 4: router splits spend the shared budget. At z 0, 2 router splits leave 2 leaf splits (5 leaves against
     the tree's 9), and it still ties.
- "At least equal" holds trivially at z >= 100 (here), where the DAG is the tree. Below that, it is within noise
  either way.

- What changed:
  - CLI: --model bdd takes --leaf probit, --split-noise and --probit-shared-eps (the last not with --path-context).
    The BDT's probit leaf code (split copies widened by noise^2, the draw margin) was already in the shared graph
    code; only the CLI and the path-context checks refused it.
  - Path cells for probit nodes (pathctx.rs, the analyst's 6.25 addendum):
    - Each probit node's table holds Gaussian latent weights, (mean, variance) per (cell, value). There is no class
      index: the ordinal probit has one latent for all three results, so "per (cell, value, class)" collapses to
      per (cell, value).
    - A new cell starts at mean 0 and variance split_noise^2, so a split changes no latent mean. The added variance
      makes predictions very slightly less confident (one 9e-4 per new cell, against beta^2 = 1).
    - The cells are summed into the probit's latent like further features. They learn with its own weights in the
      same ADF update (Probit::train_with_cells): dynamics tau^2, truncation, tempering, the eps gradient.
    - A leaf split's copies get the leaf's table, forgotten like the classifier (variances times the forget factor)
      and widened by split_noise^2 like its weights.
    - The file format writes "pathtable probit 1 <values> <cells> ...", then the cells' prior variance, the means and
      the variances. In state files, a probit node's table also stores its prior variance.
  - With probit leaves, path context needs --split-noise > 0 (the cells' prior) and refuses --probit-shared-eps.
