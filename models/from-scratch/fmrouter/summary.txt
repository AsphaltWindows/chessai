FM ROUTERS: chessai-fmrouter (2026-11-09 ~21:55-22:30, a fork of the coordinator)

Task: a binary in which a factorization machine (FM) can be a BDT router, kept for the future. The user took FM out of
the error-routers experiment (which runs on chessai-hybrid4gfx) and took probit out of routing altogether, so no spec
was written. Branch factor: the user chose 3 children. FM routers are tested at 3 and at 2.

BINARY

- Source: models/from-scratch/fmrouter-src, a copy of models/from-scratch/fastbin/hybrid4gfx-src (the source of
  chessai-hybrid4gfx). The unmodified copy rebuilt byte-identical to chessai-hybrid4gfx (md5 a3e6d4e6...).
- Build: cargo build --release -j 2 at nice 19, 51.6 s CPU, 0 warnings. Log: fmrouter/build.log.

CHANGES (lines added/removed)
- delegation.rs (+102 -10):
  - NodeKind::Fm (clap value "fm") and NodeModel::Fm(Fm). Every match covers it: kind, class_num, train, predict,
    predict_log, prediction during training, refresh (none), forget (divides the AdaGrad sums of the vectors and the
    linear part), save, the tree text format, options, and state files (tag 4).
  - DelegationParams gets `fm: FmOptions {factors, scale, seed}` (defaults 8, 0.01, 1, as --fm-*). Its Debug (the
    options a state file records) shows it only when a router or error router is FM, so every other tree's state
    files are unchanged.
  - DelegationParams::new_router_classifier(kind, categories, node, seed_offset) makes a router over branch_factor
    children. An FM router's vectors start from fm.seed plus the node's index; an error router beside a cluster router
    adds a fixed offset. Its step size is --lr-rate. Graph::new_router and new_error_router now take the node index.
    new_classifier refuses FM, so leaves can't be FMs; Graph::new asserts it too.
  - Model files: an FM router is written in FM's own text format. The parser accepts "fm" nodes only as routers whose
    class count is the branch factor. Loading takes the FM routers' factors, and the step size from the LR leaves (or
    from an FM if there are none).
- fm.rs (+52 -2): Fm::from_tokens (from_text now calls it), rate(), factors(), and write_state/read_state for exact
  resume.
- main.rs (+22 -6):
  - delegation_params passes --fm-factors/--fm-scale/--fm-seed.
  - Checks (train and self-play): --leaf fm is refused for every tree, FM routers are refused outside --model bdt, and
    --fm-factors must be 1..32 for FM routers.
  - A tree root of --leaf fm is refused. The bench's params get the defaults. Help text mentions FM routers.
- bdd.rs (+2 -2): passes the node index to new_router/new_error_router.
- ht.rs (+1): a Hoeffding tree refuses an FM root.
- Cluster routing needed no new code, so it is allowed (see below).
