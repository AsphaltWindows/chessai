THE OPTION (train)
  --pairs on|off (off)  --pairs-k 50  --pairs-z 5  --pairs-cap 2000  --pairs-shrink 0.5  --pairs-drop 0.5
  --pairs-every 1000000  --pairs-drop-after 3000000  --pairs-sample 1
  A pair = feature i value a AND feature j value b (i < j): 356,642 candidates, 2,415 active a position. After each
  example every active candidate adds the latent's standardized shift v (TrueSkill's v of the truncation, summed over
  the label's results; 0 if not finite) to S and 1 to n. Every --pairs-every examples, counted from the model's start
  (examples trained with pairs): first drops (a pair active in at least --pairs-drop-after examples since chosen with
  |mu| < 0.5 sd; its statistics restart), then adds the k candidates with the largest |z| = |S|/sqrt(n) above z (ties
  by index), up to the cap: mu 0, sd shrink x prior (0.15), statistics restarted. A chosen pair is one more weight:
  the dynamics widen it, it enters the latent's mean and variance, the truncation moves it, forget scales it. The
  pairs are summed after the model's own weights. --pairs-sample M: only candidates whose index hashes to 0 mod M.
  Model file: probit version 2 = version 1 + a "pairs" section (options, examples trained, the pairs "i a j b mu s2"
  in the order chosen). A model without pairs is version 1, byte for byte. Older binaries refuse version 2 ("unknown
  probit model version"), loudly. A model with chosen pairs plays on the float path (fixed() is None); with none yet
  (the first 1M examples) it plays in fixed point exactly as a plain probit.
  State: the candidates' (S, n) are training state, written by every pairs training as {name}N.state beside the
  model ("chessai-state 1 probit-pairs": examples trained, the pair list, 713,284 f64; 5.7 MB). `train --start
  X.model` reads X.state and checks it matches (examples trained and pair list); missing or mismatched: an error,
  unless the model has trained nothing (the driver's version 0: fresh statistics, noted on stderr).
  Refused, with an error and no output: --pairs on with a start model without pairs (pairs only from scratch),
  a pairs model trained without --pairs on, --pairs-* options without --pairs on, --label-depth, --init-forget,
  and self-play (the flag, or a pairs model as --init/--resume).
  Log (after train's "round 0: N positions" line; the driver's regex is unaffected), per training:
    pairs: 300 chosen of cap 2000; this round: 202567 examples, 2 checkpoints, added 100 (|z| min 8.71, median 9.41,
    max 11.04), dropped 0; active per position 3.386; 605209 examples since the start
  then one line per checkpoint naming every pair dropped (mu, sd) and added (|z|) as i:a&j:b, e.g.
    pairs checkpoint at 600000 examples: dropped 0; added 50 (|z|): 1:2&3:4 11.04, 50:7&54:8 11.02, ...; 300 chosen
